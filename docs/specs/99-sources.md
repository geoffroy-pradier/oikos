# Sources

- [Supabase, Self-Hosting with Docker](https://supabase.com/docs/guides/self-hosting/docker) : configuration minimale et recommandée.
- [OVHcloud, gamme VPS](https://www.ovhcloud.com/fr/vps/) : configurations, tarifs « à partir de », sauvegarde incluse.
- [Empire Immo](https://elmut.itch.io/empire-immo) : périmètre du jeu de référence (immobilier, entreprises, bourse, mairie).

Citopie et Areapolis sont cités d'après votre description ; je n'ai pas trouvé de page publique à jour décrivant leurs mécaniques. Les règles, formules et valeurs chiffrées du jeu sont des propositions de conception à valider en simulation.
